# ⚡ MB Energy Intelligence

O **MB Energy Intelligence** é uma solução completa de monitoramento elétrico desenvolvida para transformar dados técnicos em economia real. 

## 🚀 Funcionalidades
- **Dashboard em Tempo Real:** Visualização instantânea do consumo em Watts.
- **Previsão de Fatura:** Algoritmo que calcula o valor estimado da conta de luz (R$) com base no consumo atual.
- **Gráficos Dinâmicos:** Acompanhamento de picos de energia para identificação de aparelhos "vilões".
- **Interface Mobile-First:** Otimizado para visualização rápida no celular.

## 🛠️ Tecnologias
- **Backend:** Python 3 + Flask
- **Frontend:** Chart.js + HTML5/CSS3 (Dark Mode)
- **Infraestrutura:** Hospedado no Render

## 📈 Objetivo
Reduzir o desperdício de energia e proporcionar transparência total sobre os custos elétricos de residências e comércios.
